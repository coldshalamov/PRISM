# A short PRISM demo

Open the existing [Archie app](https://41d0bdfd-0065-4b0b-a973-efbe1c1a9c5e.archie.site/) and refresh once if an older screen is still open.

1. Start with the fictional table already loaded, or choose **Upload a dataset** for CSV, JSON or XLSX.
2. Choose **Ask Jev to double-check** to review the column meanings. Use **Fix a field…** if a suggestion needs correcting.
3. Check **I checked which fields identify a person**, then choose **Looks right, show me the risks**.
4. Wait for **Finding more options…** to finish. Move the **Protection level** slider from **Keep more detail** toward **Hide more**. Each position selects a real measured option. The left side explains what changed; the right side shows what still stands out and which research answers changed.
5. Choose **Download protected data** or **Save report**.

For a short spoken demo: “Removing names can leave identifying clues. PRISM checks those clues and what the protections do to the answers we care about. This slider compares options it actually tested.”

**Advanced tools** opens the detailed tables, field settings, outside-file comparison and full reports. It is optional for the guided demo. The app and pitch URLs have not changed. This is a proof of concept; a result marked **Not tested** has no measured answer.
